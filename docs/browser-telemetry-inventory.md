# Public ingress browser telemetry inventory

Live snapshot collected 2026-10-05 using `kubectl get ingress -A` and current Argo CD Application specs. The table is ingress-level: one host can appear more than once when an API and UI share it. There are **141 public route entries** across **130 distinct hostnames**.

The owner and source fields come from Argo tracking annotations/labels and Application source specs where available. “Unknown” means the live route could not be mapped to a source safely. Some legacy aliases still need source mapping; these are identified explicitly in the table. A hostname on a Waylon-owned domain does not by itself prove its content is first-party. Status records current telemetry coverage, not planned coverage.

The `k8s-pages` utility hosts include `k8s-pages.wayl.one`, `tic-tac-toe.wayl.one`, `wwdev.wayl.one`, `dev.rhiannonwalker.com`, plus the paired `b64`, `clock`, `dice`, `ninesui`, `qrcode`, `search`, `stopwatch`, `timer`, and `uuid` hosts listed in the table. The `solid-stack-dev.waylonwalker.com` route remains a legacy alias whose source repository is not located. `dnd.waylonwalker.com` is Lantern Table; its sibling checkout serves a custom Python/JavaScript app and had unrelated local changes, so it was not modified in this pass.
